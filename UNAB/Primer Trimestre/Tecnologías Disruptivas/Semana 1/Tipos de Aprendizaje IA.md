# Tipos de aprendizaje:
## Supervisado :
Set de entrenamiento es etiquetado

Ejemplos:

-Binarios, sólo se asignan dos clases (0 o 1)
-Multiclase: múltiples categorías a las observaciones

### Etapas de la clasificación:

1- Recopilación de datos.
2- Elección de un indicador de éxito.
3- establecimiento de un protocolo de evaluación (para medir el desempeño)
4- Preparación de los datos.
5- Desarrollo de un punto de referencia del modelo (Contra que comparar)
6- Desarrollo de un buen modelo y ajuste de parámetros.

### Algoritmos más comunes:
-Árbol de decisiónes
-Vecinos mas cercanos (K-NN)
-Regresión lineal
-Regresión logistica
-Redes neuronales
## No Supervisado:
Sólo hay entradas al sistema y no existen categorías.
El objetivo es detectar patrones que sirvan luego para poder etiquetar
